Measured polarity is **non-inverting** in this testbench (Iout ~ +k*Iin), so errors below are vs +k*Iin. If the MAC input convention is 'positive code sinks current', read the signs inverted.

## Mismatch Monte Carlo

- matrix: k in [1, 2, 4, 8], Iin in [-4, -1, 0, 1, 4] uA, Vout 0.4/0.9/1.4 V
- runs: 200, runs with any violation: 200 (100.0%)
- worst violation over all runs: +6.36 uA

## Findings

- Best common output bias: Vout = 0.60 V, 97/128 (k,Iin) combos within half-LSB.
- 2/128 combos never meet half-LSB anywhere in the 0.2..1.6 V sweep.
- Worst error at Vout = 0.9 V: 1.84 LSB.
- Measured polarity is non-inverting in this testbench (Iout ~ +k*Iin).
- Residual error is an odd (S-shaped) compression that grows with k; mismatch is secondary.
