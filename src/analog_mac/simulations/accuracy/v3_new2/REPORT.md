## Findings

- Best common output bias: Vout = 0.40 V, 128/128 (k,Iin) combos within half-LSB.
- 0/128 combos never meet half-LSB anywhere in the 0.10..1.30 V sweep.
- Worst error at Vout = 0.9 V: 1.17 LSB.
- Measured polarity is non-inverting in this testbench (Iout ~ +k*Iin).
- Residual error is an odd (S-shaped) compression that grows with k; mismatch is secondary.
